## Matemática

### Funções

```formula
nome: Função afim (1º grau)
formula: f(x) = ax + b
onde:
- **a**: coeficiente angular (taxa de variação)
- **b**: coeficiente linear (onde a reta corta o eixo y)
```

```formula
nome: Coeficiente angular a partir de dois pontos
formula: a = (y₂ − y₁) / (x₂ − x₁)
onde:
- (x₁, y₁) e (x₂, y₂): dois pontos da reta
```

```formula
nome: Fórmula de Bhaskara
formula: Δ = b² − 4ac  →  x = (−b ± √Δ) / 2a
onde:
- **a, b, c**: coeficientes de ax² + bx + c = 0
- **Δ**: discriminante (Δ > 0: duas raízes; Δ = 0: uma; Δ < 0: nenhuma real)
```

```formula
nome: Vértice da parábola
formula: x<sub>v</sub> = −b / 2a   e   y<sub>v</sub> = −Δ / 4a
onde:
- Se a > 0, y<sub>v</sub> é o valor mínimo; se a < 0, é o valor máximo.
```

### Progressões

```formula
nome: Termo geral da PA
formula: aₙ = a₁ + (n − 1) · r
onde:
- **aₙ**: termo na posição n
- **a₁**: primeiro termo
- **r**: razão (diferença entre um termo e o anterior)
```

```formula
nome: Termo geral da PG
formula: aₙ = a₁ · qⁿ⁻¹
onde:
- **q**: razão (quociente entre um termo e o anterior)
```

## Física

### Cinemática

```formula
nome: Velocidade média
formula: vₘ = Δs / Δt
onde:
- **Δs**: deslocamento (m)
- **Δt**: intervalo de tempo (s)
```

```formula
nome: Movimento uniforme (MU)
formula: s = s₀ + v · t
onde:
- **s₀**: posição inicial; **v**: velocidade constante; **t**: tempo
```

```formula
nome: Movimento uniformemente variado (MUV)
formula: s = s₀ + v₀ · t + (a · t²) / 2   e   v = v₀ + a · t
onde:
- **v₀**: velocidade inicial; **a**: aceleração (m/s²)
```

```formula
nome: Equação de Torricelli
formula: v² = v₀² + 2 · a · Δs
onde:
- Útil quando o problema não fala do tempo.
```

### Dinâmica

```formula
nome: 2ª lei de Newton
formula: F<sub>R</sub> = m · a
onde:
- **F<sub>R</sub>**: força resultante (N); **m**: massa (kg); **a**: aceleração (m/s²)
```

```formula
nome: Peso
formula: P = m · g
onde:
- **g**: aceleração da gravidade (perto da superfície da Terra, cerca de 9,8 m/s²; muitas provas usam 10 m/s²)
```

## Química

### Quantidade de matéria

```formula
nome: Número de mols
formula: n = m / M
onde:
- **n**: quantidade de matéria (mol)
- **m**: massa (g)
- **M**: massa molar (g/mol)
```

### Soluções

```formula
nome: Concentração comum
formula: C = m₁ / V
onde:
- **m₁**: massa do soluto (g)
- **V**: volume da solução (L)
```

```formula
nome: Concentração em quantidade de matéria (molaridade)
formula: M = n₁ / V
onde:
- **n₁**: quantidade de matéria do soluto (mol)
- **V**: volume da solução (L); a unidade é mol/L
- Não confunda com a massa molar: alguns livros escrevem [soluto] = n₁ / V.
```
